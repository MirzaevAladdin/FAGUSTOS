# 🍽 Cafe Menu Website

## 💻 Frontend Web Development Project

This is a responsive cafe menu web application built using HTML, CSS, and JavaScript.

---

## 🚀 Project Overview
This project displays a cafe menu with filtering functionality and an interactive recipe modal window.

Users can:
- View menu items
- Filter items by category (season/type)
- Open recipe details in a modal window
- Experience responsive design on mobile and desktop

---

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (DOM manipulation, events)
- Responsive Design (mobile-first approach)

---

## ✨ Features
- 🔥 Animated UI elements (text glow effect)
- 🍔 Category filtering system
- 📱 Responsive layout for mobile and desktop
- 🪟 Interactive modal for recipe details
- 🎨 Clean cafe-style UI design

---

This project was created to improve my front-end development skills, especially:
